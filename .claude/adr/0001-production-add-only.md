# ADR-0001: 本番 DynamoDB への年次データ投入は「追加のみ」とする

- 日付: 2026-09-27
- ステータス: 採用

## 背景
年次データ更新時、ローカル（DynamoDB Local）では検証のため全件削除（テーブル再作成）してから投入した。
本番でも同様に既存データを消すかを検討した。

## 決定
本番の `SapporoTrashCalendar` は **テーブル・アイテムとも削除しない。新年度データを追加投入するだけ** とする。

## 理由
- 本番テーブルは公開中の Alexa スキルが参照しており、削除・再作成中はスキルが応答できなくなる
- 過去データは Lambda（`delete_item_perday.py`）が毎日 0:00 に前日分を削除しているため、手動で消す必要がない
  - このため更新時点で本番に残っているのは直近数日分（2026-09-27 時点で 184件）のみで、これは正常
- 新年度データ（10/1〜）は既存データ（〜9/30）と日付キーが重ならないので追加だけで整合する

## 帰結
- 投入前に「既存データの最大日付 < 新データの最小日付」を確認する（`put_item` は同一キーを黙って上書きするため）
- 投入後は「総件数 = 既存件数 + 投入件数」で検証する
